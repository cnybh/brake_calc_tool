# brake_calc_tool

列车制动性能计算工具

A tool for calculating braking performance of rail transit trains


----------------------------------------

![image](https://github.com/cnybh/brake_calc_tool/blob/main/logo.png?raw=true)

------

![image](https://github.com/cnybh/brake_calc_tool/blob/main/view.png?raw=true)

------

通过读取符合ANSI编码格式的DCUTERM数据，自动计算车辆制动距离，并自动计算输出基于GB/T 44125.1（ISO 20138-1）和 GB/T 44125.2（ISO 20138-2 或 EN 14531-2）标准的平均减速度与瞬时减速度。

By reading DCUTERM data conforming to ANSI encoding format, the vehicle braking distance is automatically calculated, and the average deceleration and instantaneous deceleration are automatically calculated and output based on GB/T 44125.1 (ISO 20138-1) and GB/T 44125.2 (ISO 20138-2 or EN 14531-2) standards.
